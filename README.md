# 系统式分片纠删码库

离线归档模块需要在部分分片丢失时恢复原始对象。本库在 GF(256)（域多项式 0x11d，加法为 XOR）上从头实现已知擦除纠删码：仅恢复被明确标记缺失的分片，不承诺纠正静默损坏。

## 原理

- 构造 n×k Vandermonde 矩阵 V，0 起始行 i 取域元素 i+1，`V[i][j] = (i+1)^j`。
- G = V · T⁻¹（T 为 V 的前 k 行方阵），G 的前 k 行为单位阵，即系统式编码：前 k 片就是数据本身，后 m 片为校验。
- 参数范围 `1 <= k <= 16`，`1 <= m <= 8`，`n = k+m`；输入至多 4 MiB。
- 原长 N 决定片长 `s = ceil(N/k)`，数据连续分为 k 片并在末尾补零；空输入 s=0，得到 n 个零长有效分片。

## 接口（包 `erasure`）

```go
type Shard struct {
    Index int    // 0 起始分片索引，范围 [0, n)
    Data  []byte // 长度必须为 ceil(N/k)；空输入时零长 bytes 是有效分片
}

// 编码：返回 n 片（前 k 片数据、后 m 片校验），每片长 ceil(len(data)/k)。
func Encode(data []byte, k, m int) ([][]byte, error)

// 恢复：从任意至少 k 片重建全部 n 片及原数据。缺失索引不出现在列表中。
func Reconstruct(origLen int, shards []Shard, k, m int) (all [][]byte, data []byte, err error)
```

`Reconstruct` 拒绝：重复/越界索引、负或超过 4 MiB 的原长、片长不等于 `ceil(N/k)`、少于 k 片。求解后复核所有已给分片并检查恢复数据尾部补零；不一致即报错。注意：恰好 k 片时片间不一致不可普遍检测，本库不作虚假保证。任何路径（含错误路径）都不修改输入，输出字节与输入互不别名。

## 环境与命令

Windows 原生 Go 1.26.5，仅标准库，无第三方依赖、外部服务或 Docker。

演示（约 2 秒，展示双片丢失恢复与不足片失败）：

```
go run ./cmd/demo
```

测试：

```
go test ./... -count=1 -timeout=60s
```

测试覆盖：域乘法对照独立逐位参考、空输入零长分片、非整除长度、k≤3/m≤3 时穷举所有大小为 k 的可用索引组合、数据/校验片缺失、坏原长/片长、重复/越界索引、额外片不一致、尾部补零检查、输入不被修改且输出不别名。

## 实现范围

只实现 TASK.md 要求的核心：有限域运算、矩阵求逆、系统式编码与任意擦除恢复。不包含 UI、网络服务或长压力测试。
