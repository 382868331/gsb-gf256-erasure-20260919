# 系统式分片纠删码库

离线归档模块需要在部分分片丢失时恢复原始对象。

当前是0-1共同初始骨架，没有业务实现或参考答案。完整规格见TASK.md，API命名及模块组织可自行选择，必须满足其语义。

## 环境与命令

Windows原生Go 1.26.5，仅标准库，无第三方依赖安装步骤，无账号、密钥、外部服务或Docker。

演示：`go run ./cmd/demo`

实现后测试：`go test ./... -count=1 -timeout=60s`

初始演示只输出SCAFFOLD ONLY。初始测试尚未编写，Go会显示[no test files]。模型需补充真实库、测试和约8秒演示。

有限域矩阵构造、任意擦除恢复、长度元数据与错误原子性共同决定可恢复性。
